1. เทคโนโลยี คือ สิ่งที่มนุษย์พัฒนาขึ้นเพื่อช่วยในการทำงาน แก้ปัญหา หรือตอบสนองความต้องการในชีวิตประจำวัน โดยเป็นการนำความรู้ทางวิทยาศาสตร์ หลักการ หรือระเบียบวิธีมาประยุกต์ใช้ให้เกิดประโยชน์ในทางปฏิบัติ
2. นวัตกรรม (Innovation) คือ กระบวนการสร้างสรรค์หรือปรับปรุงสิ่งใหม่
3. Design Thinking (การคิดเชิงออกแบบ) คือ กระบวนการแก้ปัญหาและสร้างสรรค์นวัตกรรมโดยมี "มนุษย์หรือผู้ใช้งานเป็นศูนย์กลาง" (Human-Centered Design)
